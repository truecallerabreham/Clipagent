# Inserts render with HTML scenes, plus Manim for math

Inserts are HTML/SVG scenes rendered frame by frame in headless Chromium, because agents write that stack well, it covers four of the five Looks (cards, packets, hand-drawn strokes, 3D charts with three.js), and it is open-licensed. Manim renders the math-vector Look (installed only on first use), because nothing else matches 3Blue1Brown fidelity. Remotion was rejected because its license requires a paid company license for teams of 4+, which is awkward for a skill anyone can install.
